# Hello World

Hello World is an example extension: it says hello and counts how often you asked. Copy it to
start your own extension, and rewrite this guide for yours (see DEVELOPERS.md, "Your
Extension's Guide").

## Getting started

Press H in Hariku's main window. Hello World says hello, and how many times it has greeted
you.

## Other commands

- "Show Hello Dialog" opens a small window.
- "Fetch GitHub Zen Quote" fetches a short quote from GitHub and reads it.

Neither has a key. Give them one in Preferences, Input Gestures, under Hello World, or ask
Aruna by their names.

## Settings

In Preferences, Hello World:

- "Greet me when Hariku starts" says "Good day" and your name a moment after Hariku starts.
- "Your name:" is the name it greets.

## Keys and commands

- H: "Say Hello"
- No key: "Show Hello Dialog", "Fetch GitHub Zen Quote"

## Privacy

"Fetch GitHub Zen Quote" asks api.github.com for a quote. Nothing about you is sent.
