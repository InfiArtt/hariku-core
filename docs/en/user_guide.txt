1. GETTING STARTED
================================================================================

THE WELCOME
------------
The first time you start Hariku, before the main window, Hariku gets to know
you in a short conversation of eight pages. Each page's question is read
together with its first field, and the rest of the page follows a moment
later. Press Enter to go on (Next), Alt+B for Back, and Escape to stop.

  1. Hello. Choose your language: English or Bahasa Indonesia. It changes at
     once, starting with the page you are on.
  2. Your name, and what Hariku should call you. The second field fills in
     the first word of your name; change it if you like. From here on,
     Hariku uses that name: "Hey, Rafli! Finally, we meet." The third field,
     "How I talk", picks Hariku's personality: "Follow what I call you" (a
     nickname like Princess, bro or babyy changes how Hariku talks), or
     Cheeky friend, Sweet, Laid-back bro, Royal or Polite. You can change it
     later in Preferences, Profile.
  3. Where you live. Type your city and press Enter; the cities found are
     listed (use the arrow keys, then Enter to go on). Hariku then tells you
     the time there and, when you're online, the weather: "In Batam it's
     14:20 now, mostly clear, 31 degrees." Your city becomes your main
     place, called Home, in Preferences, Places; places you already had
     stay. If you have a main place already, it is shown, and pressing Next
     keeps it. Only the name you type is sent to Open-Meteo, and for the
     weather a point rounded to about 1 kilometre.
  4. Your birthday: the day and the month, and the year if you want. On the
     day, Hariku wishes you a happy birthday.
  5. Meet Aruna, Hariku's assistant (Ctrl+Alt+Backspace from anywhere, or
     the key you gave it). Try it on the page: type "what time is it" or
     "what's the date" and press Enter. Here Aruna only answers these two;
     the real Aruna does much more.
  6. Extensions Hariku suggests, from the Extension Store: tick the ones you
     want with the Space bar. The box below the list tells you about the
     one selected. Only extensions this Hariku can run, and that you don't
     have yet, are listed. Nothing is downloaded until you press Finish.
  7. Start-up: whether Hariku starts with Windows, and whether it greets you
     when it starts ("Good afternoon, Rafli. Welcome to Hariku ...").
  8. A summary of what you chose, then Finish. The extensions you ticked are
     then installed one by one, each one announced; if one fails, the others
     still install, and you can try it again in the Extension Manager.
     Press Enter once they are done.

You can skip any page: just press Next. Your name, what Hariku calls you and
your birthday are saved in Preferences, Profile, and can be changed there any
time.

Cancel (Escape) saves nothing; if you have typed something, Hariku asks
first. On the very first start, Hariku then starts as usual and the welcome
doesn't come back by itself. Open it again any time from Help > Welcome
Dialog: it shows what you have now, and changes only what you change. If
you install extensions or change the language there, Hariku offers to
restart.

If you hold the Shift key on your keyboard while the application is loading,
Hariku will start in Safe Mode instead of normal mode. You will hear a soft
"click" sound the moment Safe Mode is detected, confirming it is active. Safe
Mode is explained in full in Section 11.

After setup, the main window opens showing the calendar and a menu bar. A
system tray icon is also placed in the Windows notification area, giving you
quick access to Hariku even when the main window is hidden.


================================================================================
2. THE CALENDAR — NAVIGATION
================================================================================

The calendar is the heart of Hariku. When the main window has focus, you can
navigate it entirely with the keyboard. Every navigation action announces the
selected date aloud through your screen reader.

If a date has at least one reminder attached to it, a subtle "pen click" sound
plays as you land on it, giving you an additional audio cue.

DEFAULT KEYBOARD SHORTCUTS
---------------------------
All of the shortcuts below can be changed in the Input Gestures dialog
(Section 8). The keys listed here are the factory defaults.

  Arrow Keys:
    Left Arrow         Move to the previous day
    Right Arrow        Move to the next day
    Up Arrow           Move back one month
    Down Arrow         Forward one month
    Page Up            Move back one year
    Page Down          Forward one year

  Jump Keys (hold Ctrl):
    Ctrl + Left        Jump to the first day of the current week (Monday)
    Ctrl + Right       Jump to the last day of the current week (Sunday)
    Ctrl + Home        Jump to the first day of the current month
    Ctrl + End         Jump to the last day of the current month

  Today:
    D                  Return to today's date instantly

  Go to a Specific Date:
    Ctrl + G           Opens a text prompt. Type a date in either of these
                       formats and press Enter:
                         YYYY-MM-DD  (e.g. 2026-12-25)
                         DD/MM/YYYY  (e.g. 25/12/2026)


READING REMINDERS FOR THE SELECTED DATE
-----------------------------------------
  Space              Read all reminders for the currently selected date aloud.
                     If there are no reminders, Hariku will say so.
                     If there are reminders, the Agenda dialog opens showing
                     a list of all reminders for that date.

ADDING A REMINDER TO THE SELECTED DATE
----------------------------------------
  Enter              Opens the Add Reminder dialog for the currently
                     selected date. See Section 3 for details.
  N                  Quick reminder: type a reminder in one sentence, such
                     as "take medicine tomorrow at 8 am, every day".


================================================================================
3. REMINDERS
================================================================================

ADDING A REMINDER
------------------
Navigate to the date you want on the calendar, then press Enter (or choose
Reminders, Add reminder). The "Add Reminder" dialog opens. Fill in:

  Title      — A short description of the reminder (e.g. "Doctor appointment").
  Date       — The selected date; change it here if you like (YYYY-MM-DD or
               DD/MM/YYYY).
  Time       — The time the reminder should fire, in HH:MM 24-hour format
               (e.g. 14:30 for 2:30 PM).
  Repeat     — Does not repeat, daily, weekly, monthly or yearly.
  How often  — For a repeating reminder: every day, every 2 days, every
               3 weeks... up to 30. A monthly reminder on the 31st comes on
               the last day of shorter months.

Or type the whole reminder in the field above the title, "Or type it in one
sentence" (Shift+Tab twice from the title), for example "dentist next Monday
at half past nine", and press Enter or Fill in. Hariku fills in the fields
and tells you what it understood.

Press Save Reminder (Alt+S) to save. The reminder is stored locally on your
device.

QUICK REMINDER
---------------
Press N anywhere in the main window (or choose Reminders, Quick reminder)
and type one sentence, such as "take medicine tomorrow at 8 am, every day",
"call Budi in 30 minutes" or "minum obat besok jam 8 pagi, tiap hari".
Press Enter: Hariku reads back what it understood, for example "Take
medicine, Friday 25 September 2026, at 08:00, every day. Save?". Press Enter
again or Save to save it, or "Edit in full reminder dialog" to check it in
the dialog above. English and Indonesian are always understood, also mixed
in one sentence; German can be turned on in Preferences, Reminders. The
sentence is read on your computer and never sent anywhere.

HOW REMINDERS FIRE
-------------------
Hariku runs a background daemon that checks for due reminders every 30 seconds.
When a reminder's date and time match the current moment, a dialog appears:

  - The reminder title is announced aloud.
  - A Windows notification sound plays.
  - The Reminder dialog offers two options:
      Snooze (5 min)  — Delays the reminder by 5 minutes.
      Mark as Done    — Dismisses the reminder permanently.

A reminder will only fire once per minute slot. If you have already marked it
as done, it will never fire again.

VIEWING REMINDERS FOR A DATE
------------------------------
Press Space on any date in the calendar to open the Agenda dialog for that
date. The Agenda lists all reminders with their times and completion status.

IMPORTANT NOTE
--------------
Snooze customisation and editing a saved reminder are not part of the core
application yet.


================================================================================
4. SOUND & SPEECH FEEDBACK
================================================================================

Hariku provides rich audio feedback through two channels:

SCREEN READER SPEECH
---------------------
If a supported screen reader is running (NVDA, JAWS, or SAPI), Hariku speaks
date announcements, reminder titles, error messages, and status updates through
it automatically. No configuration is needed.

INTERNAL SOUNDS
----------------
Hariku also plays its own subtle sound effects for navigation and events:

  move.wav       — Plays every time you navigate to a different date.
  penClick.wav   — Plays when you land on a date that has reminders.
  start.wav      — Plays once on application startup.
  history.wav    — Plays when Safe Mode is detected at startup.

ADJUSTING VOLUME
-----------------
Hariku's internal sounds have their own volume control, independent of your
system volume. Two hotkeys let you adjust it without opening any dialog:

  F5   — Decrease Hariku's sound volume.
  F6   — Increase Hariku's sound volume.

You can also set a precise volume level using the slider in
Preferences > General (Section 5).

TOGGLING SPEECH INTERRUPTION
------------------------------
By default, each new spoken message interrupts the previous one (so navigating
quickly through dates does not stack up announcements). You can toggle this
behaviour in Preferences > General using the "Interrupt speech" checkbox. for NVDA this will only work mostly when you use sleep mode on.

5. PREFERENCES
================================================================================

Open the Preferences dialog from:
  - Menu: Preferences > Open Preferences
  - Keyboard: Ctrl + P

The dialog is organised into lists of window. use an arrow to switch between them.

GENERAL Winddow
------------
  Play startup sound
      Whether to play the startup chime when Hariku opens.

  Interrupt speech
      When checked (default), a new announcement cancels the previous one.
      Useful when navigating quickly. Uncheck if you want all speech to queue.

  Start Hariku with Windows
      Adds or removes Hariku from Windows startup via the registry.

  Global Volume  (slider, 0-100)
      Controls the volume of all internal Hariku sounds (move, click, etc.).
      This is separate from your system volume.

  Date Format  (dropdown)
      Controls how dates are announced and displayed. Available formats:
        Long (Weekday, Day Month Year)  e.g.  Tuesday, 16 June 2026
        Long (Day Month Year)           e.g.  16 June 2026
        Medium (Wkdy, Day Mon Year)     e.g.  Tue, 16 Jun 2026
        Medium (Day Mon Year)           e.g.  16 Jun 2026
        Short (DD/MM/YYYY)              e.g.  16/06/2026
        Short (DD-MM-YYYY)              e.g.  16-06-2026
        International (YYYY-MM-DD)      e.g.  2026-06-16

  Language  (dropdown)
      Changes the display language of the application interface. A restart is
      required for the language change to take full effect.

  Window Close Behaviour  (radio buttons)
      Defines what happens when you press the X button or close the window:
        Minimize to Tray   — Hides the window; Hariku stays running in the tray.
        Quit Hariku        — Exits the application completely.
        Show Exit Options  — Asks you what to do each time.

  Public Telemetry Data
      Hariku collects fully anonymous usage statistics (OS version, language,
      active extensions) to help improve the application. This data contains
      no personal information. You may opt out here at any time. The collected
      data is publicly viewable at sp.novarealm.cloud/stats.

  Check for Updates  (button)
      Manually triggers an update check right now.

EXTENSIONS Window
---------------
  Controls what Hariku does when a new version of an installed extension is
  available from the extension store:

    Notify me when updates are available  (default)
        Hariku shows a notification but does not install anything automatically.
    Update automatically
        Extensions are updated silently in the background without asking.
    Do nothing
        Extension updates are ignored entirely.

ADVANCED Window
-------------
  Log Level  (dropdown)
      Controls how much detail is written to the debug log file:
        DISABLED  — No logging at all.
        INFO      — Normal operational messages (default).
        DEBUG     — Verbose output; useful for tracking down bugs.
        WARNING   — Only warnings and errors.
        ERROR     — Only errors.

  Open Data Folder  (button)
      Opens the folder where all Hariku data (reminders, extension data,
      settings) is stored. Useful for manual backup.

  View Log File  (button)
      Opens the current debug log in your default text editor.

  Clear Cache  (button)
      Removes cached extension assets and temporary files.

Note: The Advanced Window also shows any additional panels injected by installed
extensions.


================================================================================
6. THE EXTENSION SYSTEM
================================================================================

Hariku V2's most important feature is its extension system. Instead of a
single large application, the core is deliberately minimal. Every major feature
is a self-contained "extension" that plugs into the core.

WHY EXTENSIONS?
----------------
  - If one extension crashes, the rest of Hariku keeps running perfectly.
  - You only install what you need. Unused features take up no memory.
  - Extensions can be updated independently, without touching the core app.
  - Developers can write and share their own extensions.

EXTENSION FILE FORMAT (.hrk)
------------------------------
A compiled extension is a single file with the ".hrk" extension. It is
essentially a zip archive containing the extension's code and metadata.

Extensions can also exist as unpacked folders during development, which
allows "hot-reloading" — the ability to reload an extension's code on the
fly without restarting Hariku.

WHAT COMES PRE-INSTALLED?
--------------------------
The following extensions ship with Hariku V2 in this early testing phase:
  date_calculator
      Provides date arithmetic — calculating the number of days between
      two dates or adding/subtracting days from a given date.

  developer_news
      Displays the latest developer news and announcements from the Hariku
      team inside the application.

  developer_toolkit
      Tools and utilities aimed at extension developers. Allows hot-reloading
      of unpacked extensions for rapid iteration.

  diary
      A private, encrypted diary with mood tracking. Lets you write personal
      entries linked to specific dates.

  ghost_taskbar
      Utility that cleans up orphaned taskbar entries from crashed processes.

  quotes
      Displays a random motivational quote. Can be configured to show a
      new quote on startup.

  wikipedia_reader
      Lets you look up and read Wikipedia articles from within Hariku.

Note: Many extensions from Hariku V1 are still being ported and are not
yet available in this early testing phase. They will appear in the
extension store as they are completed.

7. THE EXTENSION MANAGER
================================================================================

Access the Extension Manager from:
  - Menu: Extensions > Manage Extensions
  - Keyboard: Ctrl + X

The Extension Manager is where you install, update, enable, disable and
remove extensions. It has four tabs; Ctrl+Tab moves to the next one. Every
tab has the same controls, in this order:
  Search      Type a word from an extension's name, description or author.
              The list narrows as you type, and Hariku says how many match
              when you stop typing.
  Extensions  The list: Name, Version and Status.
  Details     Who made the extension, where it came from, what's new or
              wrong, and what it does.
  Buttons     The tab's buttons. A button that can't be used for the
              selected extension is skipped by Tab.
Below the tabs, Refresh asks the Extension Store again and Close (or Escape)
closes the window. The Installed tab is ready at once; the other tabs fill in
when the store answers, and Hariku remembers the answer for ten minutes.

INSTALLED TAB
--------------
Every installed extension that can run on this Hariku.
  Enable / Disable
      Disabling an extension keeps it installed but stops it from loading.
      Restart Hariku to finish.
  Remove (or Delete in the list)
      Deletes the extension from your computer, after asking you. Extensions
      that come with Hariku can be disabled but not removed.
  Update
      When the store has a newer version, its Status says so.
The Status also says when an extension isn't running: it needs a newer
Hariku, its manifest is broken, or it stopped with an error when Hariku
started. Details says which, and what to do.

UPDATES TAB
------------
The installed extensions the store has a newer version of, such as
"Weather, 1.1 to 1.2, Ready to update". Update (or Enter) updates the
selected one and "Update all" updates them all. A new version that needs a
newer Hariku says "Needs Hariku 2.9" and can't be installed; "Check for
Hariku updates" gets the new Hariku, and the version you have keeps working.

AVAILABLE TAB
--------------
The store's extensions you don't have yet, official and community. Install
(or Enter) downloads the selected one. An extension that needs a newer
Hariku says so and can't be installed.

INCOMPATIBLE TAB
-----------------
Like NVDA's add-on store: extensions made for a Hariku older than this one
still runs. Hariku doesn't load them. Update one if the store has a newer
version, or remove it. No Hariku 2 update has broken older extensions, so
this tab is empty for now.

Nothing jumps while you work: an extension you install, update or remove
stays where it is in the list, and its Status says what happened (for
example "Installed, restart Hariku to use it").

EXTENSION UPDATES
------------------
Hariku checks for extension updates automatically in the background 6 seconds
after startup (to avoid slowing down the boot process). What happens when an
update is found depends on your setting in Preferences > Extensions:
  - Notify: You receive a notification and choose whether to update.
  - Auto-update: The update is applied silently.
  - Do nothing: The update check runs but you are never informed.

8. INPUT GESTURES (KEYBOARD SHORTCUTS)
================================================================================

Every keyboard shortcut in Hariku — including those added by extensions — can
be viewed and customised in the Input Gestures dialog.

OPENING INPUT GESTURES
-----------------------
  - Menu: Preferences > Open Preferences, then navigate to the
    "Input Gestures" Window inside the dialog.
  - Keyboard: Ctrl + P, then navigate to Input Gestures.

THE GESTURE TREE
-----------------
Shortcuts are organised in a tree:

  Category (e.g. "Calendar Navigation", "Hariku Core", extension names)
    Action description (e.g. "Move to the next day")
      Ctrl + Right [LOCAL]
      Ctrl + Alt + Right [GLOBAL]

A shortcut marked [LOCAL] only works when Hariku's main window has focus.
A shortcut marked [GLOBAL] works system-wide, even when Hariku is minimised
or behind other windows.

ADDING A NEW SHORTCUT
----------------------
1. Select an action in the tree (click the action description row).
2. Click "Add Key".
3. The "Add Key" dialog opens. Hold the modifier keys you want (Ctrl, Shift,
   Alt, and/or the Windows key), then press the main key.
   Example: to assign Ctrl + N, press and hold Ctrl, then press N.
4. The combination is shown as a live preview. Release all keys and the
   dialog confirms automatically.
5. Press Escape at any time to cancel without saving.

Tip: A single action can have multiple shortcuts assigned to it. This is
useful when you want both a local and a global shortcut for the same action.

REMOVING A SHORTCUT
--------------------
1. Expand the action in the tree to reveal its assigned shortcuts.
2. Select the shortcut you want to remove.
3. Click "Remove Key".

GLOBAL vs. LOCAL
-----------------
When a shortcut node is selected, the "Make this shortcut Global" checkbox
becomes active. Tick it to make the shortcut work system-wide. Untick to
restrict it to when Hariku is focused.

IMPORTANT: Changes to Input Gestures are saved when you close the Preferences
dialog.


================================================================================
9. SYSTEM TRAY & CLOSE BEHAVIOUR
================================================================================

Hariku places an icon in the Windows system tray (notification area) when it
is running. Right-clicking the tray icon shows a menu with quick actions:
  - Show / Hide the main window.
  - Access Preferences.
  - Exit Hariku.

You can also toggle the main window's visibility at any time using the global
hotkey:
  Alt + Ctrl + H  (default, works system-wide)

This is especially useful if Hariku is minimised to the tray and you want to
bring it back without pressing alt tab.

ARUNA, THE COMMAND BAR
-----------------------
  Ctrl + Alt + Backspace  (default, works system-wide)

Opens Aruna, Hariku's command bar: a small window called "Aruna", from anywhere, even
when Hariku is hidden in the tray. Type a command, such as "latest
earthquake", "what time is it" or "evening summary", or a reminder, such as
"remind me to take medicine tomorrow at 8", and press Enter:

  - A command runs at once. The bar closes first, so you are back where you
    were, and a window the command opens opens as usual.
  - A command that only tells you something, such as the time, the weather
    or the latest earthquake, keeps Aruna open: the answer shows in "Last
    result", and you can type the next command straight away (what you typed
    is selected, so typing replaces it). A saved reminder keeps it open too.
    Turn this off in Preferences, Aruna, "Keep Aruna open after an answer".
  - A reminder is read back first ("... Save?"). Press Enter again (or say
    "yes") to save it, or Escape to cancel.
  - When Hariku isn't sure, it asks "Did you mean ...?". Enter runs it,
    Escape doesn't.

Every action of Hariku and of your extensions can be run this way, in English
or Indonesian. Tab reaches the "Last result" field, which shows what Hariku
last said, then "Status": "Aruna is thinking..." while an answer is on its
way, then "Aruna answered". Escape closes the bar. A soft sound plays when you
send a typed command and another when Aruna answers; turn them off in
Preferences, Aruna, "Play Aruna's sounds" (a sound theme can replace them). The answers are spoken with your Hariku
Voice when you have set one up (Preferences, Hariku Voice, "Read answers to
commands"). With the Voice Control extension, press Ctrl + Alt + Backspace again
while the bar is open, and speak after the tone instead of typing.

Voice Control 1.1 can also open Aruna when you say a wake phrase, "Hey Aruna"
or one you choose, so you don't have to press a key. In Preferences, Voice
Control:

  1. In the list at the top, select "Wake phrase listener" and press
     Download (42.4 MB from GitHub: sherpa-onnx and an English keyword model).
  2. Tick "Listen for a wake phrase", and type your phrase in "Wake phrase".
     "About this phrase" tells you when a phrase is one word, very short or
     common (easily heard by mistake). English words work best with this
     model; names like Aruna may need the High sensitivity.
  3. Press "Test the wake phrase...", and after the tone say the phrase a few
     times in 20 seconds. Hariku says "Heard it" each time it hears you, then
     how many times it heard you. If it missed you, choose High in "Wake
     phrase sensitivity" and test again; if it wakes up by mistake, choose
     Low. Press OK to save.

Say the phrase, and Aruna opens with the tone and listens to your command.
With Voice Control 1.2 and Hariku 2.9 you choose what the phrase does in
"When you say the wake phrase": "Open Aruna" (the window opens and gets the
focus) or "Listen without opening a window" (the window you're in keeps the
focus and your screen reader stays there; you talk, Aruna answers aloud,
asks and hears "yes" or "no" by voice, and closes by itself when it's done).
The Status line on the page says whether Hariku is listening for your phrase.
It doesn't listen while Hariku or your screen reader speaks through Hariku,
while Voice Control listens to a command, or, if you tick "Pause the wake
phrase during quiet hours", during quiet hours. The command "Pause or resume
the wake phrase" (no key by default: give it one in Input Gestures, or ask
Aruna for it) pauses it until you resume it or restart Hariku. The microphone
stays on your computer: nothing is saved or sent anywhere. A headset stops
your screen reader's voice from reaching the microphone.

TIMER & ALARM (EXTENSION)
--------------------------
With the Timer & Alarm extension (from the Extension Store; it needs Hariku
2.9), you set alarms and timers by typing or saying them to Aruna, in English
or Indonesian.

Alarms. Say for example "alarm tomorrow at 6 AM", "set alarm tomorrow at 2
for football", "wake me up at 5", "alarm besok jam 5 pagi" or "alarm setiap
hari jam 5 sholat subuh". Aruna reads the alarm back with its day, its date
and its time with AM or PM (in Indonesian: dini hari, pagi, siang, sore or
malam), for example: Alarm "football", tomorrow, Saturday 26 September, at
2:00 AM. Set it? Press Enter or say "yes" to set it. An hour said alone, such
as "at 2", is read like this:

  - With a day ("tomorrow at 2") or a repeat ("every day at 5"): the first
    such hour on that day, 2:00 AM or 5:00 AM.
  - With no day ("at 2"): the next 2 o'clock to come.
  - "Wake me up" is always the morning.

If that is not what you meant, say "no", then just the time again, for
example "at 2 PM" or "jam 2 siang", and Aruna asks again. When you give no
time ("alarm tomorrow"), Aruna asks for it instead of guessing. A time that
has already passed today, said without a day, is set for tomorrow, and Aruna
says so.

Timers start at once: "timer 10 minutes", "timer tea 3 minutes", "set a timer
for an hour and a half", "timer setengah jam", "hitung mundur 90 detik".
Several can run at the same time.

You can also say: "cancel the tea timer", "cancel all timers", "delete the
football alarm" (Aruna asks first), "how long is left", "list my alarms".

When an alarm or timer is due, it rings even when Hariku is hidden in the tray
and during quiet hours: a sound, then what it is ("Alarm: football"), again
every 10 seconds. It opens no window and doesn't move your focus. To stop it,
press any key, or tell Aruna "stop". To snooze it, tell Aruna "snooze" or
"snooze 10 minutes", even right after a key stopped it. If nobody stops it,
it rings for 3 minutes (you can change this), and Hariku tells you what you
missed when you next press a key. An alarm that came due while Hariku was
closed is mentioned once when Hariku starts again. The Morning Briefing says
today's alarms. If you use Hariku Voice for reminders, alarms are spoken with
that voice too.

In Preferences, Timer & Alarm, you find your alarms and timers (Delete or
Remove deletes one, after asking), "Stop ringing", the alarm and timer sounds
(Windows' own alarm sounds, with a Test button that plays 3 seconds), how long
a ring lasts and how long a snooze is. The commands "Stop the ringing alarm or
timer", "Snooze the alarm" and the others have no key by default; give them
one in Input Gestures if you like. Everything stays on your computer.

WORLD TRIP (EXTENSION)
-----------------------
With the World Trip extension (from the Extension Store; it needs Hariku 2.9;
"Keliling Dunia" in Indonesian), you fly anywhere by asking Aruna: "take me to
Tokyo", "fly to Seoul", "visit New York", "bawa aku ke Tokyo", "terbang ke
Paris", "jalan-jalan ke Istanbul". A country lands in its capital or its
best-known city ("take me to Japan" flies to Tokyo), and "take me anywhere"
("bawa aku ke mana saja") picks a surprise city.

  1. Departure: a cabin chime, then the captain's announcement, for example
     "Flight from Batam to Tokyo, about 5,300 kilometres, roughly 7 hours.
     Please fasten your seat belt." (the distance from your main place in
     Preferences, Places), then the engines. Press any key, or say "skip", to
     skip straight to the arrival.
  2. Arrival: a chime, then the city, its local time, how far ahead of or
     behind home it is, and the weather: "Welcome to Tokyo, Japan. Local time
     21:30, Friday night, 2 hours ahead of Batam. 18 degrees, drizzle."
  3. A greeting in the local language for the time of day, with "welcome to
     Tokyo", spoken by a voice of that language ("Konbanwa! Tōkyō e
     yōkoso!"), then what it means. Native voices come from Hariku Voice's
     sources: Edge Voices (from the Extension Store) has one for nearly every
     language; Piper and Windows voices are used when they have one. Without
     one, the greeting is read in your own voice, spelled out.
  4. Local radio: a live station from that city or country (from the Radio
     Browser directory) plays quietly, and turns itself down while Hariku
     speaks.

During the trip, ask Aruna:
  - "tell me about this city" / "ceritakan tentang kota ini": a few sentences
    from Wikipedia, in your language when it has them, else in English.
  - "teach me a phrase" / "ajari aku satu kalimat": an everyday phrase (thank
    you, excuse me, how much is this, delicious, where is the toilet, nice to
    meet you, goodbye, cheers) in the native voice, then how to say it and what
    it means; a different one each time. About 30 languages are included.
  - "next station" / "ganti stasiun", "radio louder" or "keraskan", "radio
    quieter" or "kecilkan", "which station is this".
  - "what time is it there" / "jam berapa di sana", "where am I" / "di mana
    aku".
  - "go home" / "pulang": the radio stops and you land back home.

Everything the trip says shows in Aruna's "Last result", and the trip goes on
when you close Aruna. A new trip replaces the one you are on. The radio stops
when Hariku closes. In Preferences, World Trip, you can turn off the departure
announcement, the engine sound, the radio or native voices, set the radio's
volume, and see which voice each language would use. The commands have no key
by default; give them one in Input Gestures if you like. Only the destination
is sent to Open-Meteo, Wikipedia and Radio Browser; your own place stays on
your computer.

ORBIT (EXTENSION)
------------------
Orbit (it needs Hariku 2.9) is a small multiplayer text game on a space
station orbiting the Earth, played with other Hariku users: hang out and chat
in the Cantina, look down at Indonesia from the Observation Deck, repair the
reactor, fly cargo to the Moon, trade on the Promenade and take small
missions. The station has ten places: the Dock, the Promenade, the Cantina,
the Observation Deck, Engineering, Hydroponics, the Medbay, the Bridge, the
Cargo Bay and your own cabin, where nobody else can come.

  1. The first time, open Preferences, Orbit: type a character name (3 to 20
     letters and digits) and choose a job (pilot, engineer, trader, scientist
     or security officer), then press Connect. Your character is kept on the
     server; the name and job boxes are only used for that first visit.
  2. Open the Orbit window with "Open Orbit" (no key by default; give it one
     in Input Gestures) or by telling Aruna "orbit" or "buka orbit". It has
     the Messages list (newest last; read it with the arrow keys; a new
     message never moves your focus), the Command field (Enter sends; Up and
     Down bring back earlier commands), Connect or Disconnect, Help and the
     status. Escape hides the window; the game goes on.
  3. Type commands in Indonesian or English: "pergi ke kantin" or "go to the
     cantina", "lihat" or "look", "lihat Sari", "bilang halo" or "say hi"
     (or start with a quote mark), "bisik Sari ketemu di dek", "teriak halo
     semua", gestures ("senyum", "lambai", "tertawa", "peluk Sari", "smile",
     "wave"), "siapa" or "who", "tas" or "inventory", "beri Sari 50 kredit",
     "deskripsi aku" followed by a few words. "bantuan" or "help" lists them
     all; "ulangi" or "repeat" reads the last message again.

Work: engineers type "kerja" in Engineering and repeat the reactor's tones by
typing their numbers ("3 1 4 2"); pilots type "kerja" at the Dock for a cargo
run to the Moon (about a minute, and you can still whisper and shout while
you fly); traders get a market report anywhere, then buy low and sell high on
the Promenade ("harga", "beli 2 kopi", "jual semua kopi"), where prices move
every few minutes. Everyone can do missions: "misi" reads today's board,
"ambil misi 1" takes one, "ambil peti" picks up what it needs, and
"selesaikan misi" delivers it. Work pays credits, with a short break before
the next shift.

From Aruna, typed or spoken (the wake phrase too), put "orbit" in front:
"orbit pergi ke kantin", "orbit bilang halo", "orbit bisik Sari nanti ya",
"orbit siapa online", "orbit lihat sekitar", "orbit cek kredit". The answer
shows in Aruna's Last result.

What happens is read aloud as it comes, in your language. Other players'
words are read in a voice of their own (always the same one for the same
player) when Hariku Voice has at least two voices of your language: Edge
Voices, from the Extension Store, adds two Indonesian voices; otherwise your
usual voice reads everything. Your own actions are only confirmed briefly
("Terkirim."), and the Messages list keeps the whole line. Sounds tell what
happened: a door when you move, a chime when someone arrives or leaves, a
soft sound in your right ear for a whisper, the reactor's tones from left to
right. While the window is open, a quiet sound of the place plays (the vents,
the Cantina's murmur, the reactor's thrum, the garden's water) and goes quiet
while Hariku speaks. In Preferences, Orbit, you can change the server
address, turn off speaking messages, the players' voices, the ambience (and
set its volume) or the sounds. Commands from Aruna are always answered aloud.

Orbit connects only when you open it, press Connect or give it a command, and
reconnects by itself if the connection drops. "sambungkan" or "putuskan"
("connect", "disconnect") connects or disconnects. See PRIVACY.md for what the
server keeps.

11. SAFE MODE
================================================================================

Safe Mode is a built-in recovery mechanism. When Hariku is in Safe Mode, the
Extension Manager is completely bypassed. No extensions load. The application
runs as a pure, stable core.

Use Safe Mode when:
  - An extension is causing Hariku to crash on every launch (a "boot loop").
  - You want to test whether a problem is caused by an extension or the core.
  - You need to uninstall a misbehaving extension without it loading.

HOW TO ENTER SAFE MODE
-----------------------
Method 1 — Keyboard at startup:
  Hold the Shift key on your keyboard before or just as Hariku is launched.
  Keep holding Shift until you hear a soft "click" sound. That click confirms
  that Safe Mode has been detected. You can release Shift at that point.

Method 2 — From within Hariku:
  Go to File > Exit Options > Restart in Safe Mode.
  Or press Ctrl + Q to open Exit Options and select "Restart in Safe Mode".

Method 3 — Command line:
  Run hariku.exe --safe-mode from a terminal.

WHAT CHANGES IN SAFE MODE?
----------------------------
  - The title bar shows "(Safe Mode)" to remind you of the current state.
  - All extensions are skipped. Their menus and hotkeys do not appear.
  - The extension store and update checker do not run.
  - Everything else (reminders, preferences, the calendar) works normally.

RETURNING TO NORMAL MODE
-------------------------
Simply close Hariku and relaunch it without holding Shift, or use
File > Exit Options > Restart.


================================================================================
12. CHECKING FOR UPDATES
================================================================================

Hariku checks for updates to the core application and to individual extensions.

CORE APPLICATION UPDATES
-------------------------
An automatic check runs in the background shortly after startup. You can also
trigger a manual check at any time from Help > Check for Updates or from the
button in Preferences > General.

Updates are delivered in three tiers, each with a different visual style:

  Critical Update  (red banner)
      Addresses a severe bug, crash, or security issue. If the server marks
      the update as "forced", the dialog cannot be dismissed and must be
      installed. If it is not forced, you may still choose to install or skip.

  Recommended Update  (amber banner)
      An important fix that is not immediately dangerous. You may defer it,
      but only up to three times. After three deferrals, it escalates to
      critical behaviour.

  Optional Update  (blue banner)
      Minor improvements or new features. You may skip it freely.

When you accept an update, Hariku downloads the installer to your system's
Temp folder and launches it silently. Hariku then closes automatically to allow
the installer to replace the application files. After installation completes,
you can relaunch Hariku normally.

EXTENSION UPDATES
------------------
Extension updates are checked 6 seconds after startup. The behaviour when an
update is found is controlled by Preferences > Extensions:
  - Notify me (default): You receive an in-app notification.
  - Auto-update: Extensions are updated silently.
  - Do nothing: Updates are ignored.

13. CRASH REPORTER
================================================================================

If Hariku encounters an unhandled error, instead of silently closing or
freezing, the Crash Reporter dialog appears. It shows:

  - A plain-language description of what went wrong.
  - The technical traceback (error log) for reference.
  - A "Send Report" button that securely transmits the error details to the
    development team so the bug can be identified and fixed.

You can also copy the traceback text manually if you prefer to report via
GitHub Issues (Help > Report a Bug).

The crash log is always saved to the Hariku log file in your system's Temp
folder regardless of whether you send the report. You can view it from
Preferences > Advanced > View Log File.


================================================================================
14. TELEMETRY & PRIVACY
================================================================================

Hariku collects a small amount of anonymous data on startup to help us
understand how the application is being used and to prioritise improvements.

WHAT IS COLLECTED
------------------
  - Your operating system version.
  - Your Hariku version.
  - Your display language.
  - The names of extensions you have installed.
  - An anonymous session ID (a random number generated fresh each launch;
    it is not stored or linked to your identity in any way).

WHAT IS NEVER COLLECTED
------------------------
  - Your name, email, or any account information.
  - The content of your reminders or diary entries.
  - Your calendar data.
  - Your file system or application activity outside of Hariku.

WHERE THE DATA GOES
--------------------
The data is sent to the Hariku analytics service and is viewable publicly by
anyone at sp.novarealm.cloud/stats. There are no private or hidden metrics.

HOW TO OPT OUT
---------------
Go to Preferences > General, scroll to the "Public Telemetry Data" section,
and uncheck "Share my anonymous usage data publicly". The change takes effect
immediately. No restart required.

15. TROUBLESHOOTING
================================================================================

HARIKU CRASHES ON STARTUP / BOOT LOOP
---------------------------------------
An extension is most likely the cause. Start Hariku in Safe Mode (hold Shift
during launch) to bypass all extensions. Once in Safe Mode, go to
Extensions > Manage Extensions, identify the problematic extension, and
remove or disable it. Then restart normally.

THE KEYBOARD IS UNRESPONSIVE IN THE "ADD KEY" DIALOG
------------------------------------------------------
This was a known bug in version 2.0.0, fixed in version 2.0.1. Please update
Hariku to the latest version via Help > Check for Updates. In the meantime,
press Ctrl+Alt+Delete to open Task Manager and end the Hariku process, or
press Escape to cancel the dialog (2.0.1 and later).

A SHORTCUT I PRESSED DID THE WRONG THING
------------------------------------------
Two shortcuts may be conflicting. Open Preferences > Input Gestures and look
for the action that should have fired. If the key is assigned to a different
action, remove it from there and re-assign it to the correct one.

HARIKU IS NOT SPEAKING
------------------------
Make sure your screen reader (NVDA, JAWS) is running, or check that your
system audio is not muted. Also verify that the volume in
Preferences > General is not set to zero.

THE DATE FORMAT SOUNDS WRONG
------------------------------
Go to Preferences > General and try a different Date Format option. The format
controls both the speech output and how dates appear visually.

AN EXTENSION IS NOT APPEARING AFTER INSTALL
---------------------------------------------
After installing an extension, Hariku needs to be restarted for it to load.
If you have already restarted and the extension still does not appear, check
that it is Enabled in Extensions > Manage Extensions.

I NEED TO FIND MY DATA FILES
------------------------------
Go to Preferences > Advanced > Open Data Folder. This opens the folder where
all your reminders, settings, and extension data are stored. You can copy
this folder to back up your Hariku data.

I NEED MORE HELP
-----------------
  Community support:   Help > Get Support  (opens the GitHub Discussions page)
  Report a bug:        Help > Report a Bug (opens the GitHub Issues page)
