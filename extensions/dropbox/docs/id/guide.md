# Dropbox

Dengar apa yang sedang dikerjakan Dropbox dan salin link bersama tanpa meninggalkan
pekerjaanmu. Hariku memberi tahu saat file yang kamu simpan sedang disinkronkan dan sudah
tersinkron, saat seseorang mengubah file di folder yang kamu bagikan atau membagikan
sesuatu denganmu, dan menyalinkan link Dropbox sebuah file untukmu. Butuh Hariku 2.9 atau
yang lebih baru. Hariku tidak pernah mengunggah, mengunduh, atau membaca isi file-mu: yang
menyinkronkan tetap aplikasi Dropbox di komputermu.

## Mulai

Pasang Dropbox dari Toko Ekstensi, lalu sambungkan akunmu:

1. Buka Pengaturan (Ctrl+P di jendela Hariku), pilih Dropbox, lalu tekan "Sambungkan
  Dropbox".
2. Browser-mu membuka halaman masuk Dropbox. Masuk, lalu pilih Allow (Izinkan).
3. Browser kembali ke Hariku dengan sendirinya; halamannya bilang tab itu boleh ditutup.
  Hariku mengucapkan "Dropbox tersambung sebagai" dan namamu, dan kolom Akun Dropbox
  menampilkan nama dan email-mu.

Kamu punya waktu lima menit untuk masuk. Selama Hariku menunggu, tombolnya menjadi
"Batalkan masuk".

Kabar tentang file-mu sendiri juga butuh aplikasi Dropbox di komputer ini. Kolom "Folder
Dropbox di komputer ini" menampilkan foldernya. Kalau aplikasinya tidak ada, atau
foldernya milik akun Dropbox lain, kabar itu mati, tapi link dan kabar dari orang lain
tetap jalan.

### Kalau Dropbox menampilkan kode

Kalau port yang dipakai Hariku sedang dipakai program lain, Dropbox menampilkan kode di
browser, bukan kembali ke Hariku. Salin kodenya, tempel ke kolom "Kode dari Dropbox" yang
muncul di halaman Dropbox di Pengaturan, lalu tekan "Pakai kode".

### Memutuskan sambungan

"Putuskan Dropbox" di halaman yang sama mengeluarkan Hariku dari Dropbox dan menghapus
tanda masuknya dari komputer ini. Kalau Dropbox tidak lagi menerima tanda masuk itu,
misalnya karena kamu mencabut akses Hariku di situs Dropbox, Hariku sekali mengucapkan
"Dropbox terputus", dan kamu bisa menyambungkannya lagi.

## Kabar tentang file-mu

Saat kamu menyimpan atau menambah file di folder Dropbox, Hariku menunggu sebentar lalu
menanyakan ke Dropbox apakah versi itu sudah sampai:

- "Menyinkronkan laporan.pdf ke Dropbox..." selama diunggah, lalu "laporan.pdf sudah
  tersinkron."
- Untuk beberapa file: "Menyinkronkan 3 file ke Dropbox..." lalu "Dropbox-mu sudah up to
  date."
- File yang tiga menit setelah terakhir kamu ubah belum juga tersinkron disebutkan sekali:
  "laporan.pdf belum tersinkron; cek aplikasi Dropbox."

Hariku tidak mengurusi file yang diunduh aplikasi Dropbox (pekerjaan orang lain, lihat di
bawah), file sementara Office dan program lain, desktop.ini dan file sistem sejenisnya,
serta file online-only, yang tidak pernah dibukanya supaya tidak ikut terunduh.

Kata-katanya bisa sedikit berbeda, mengikuti gaya bicara Hariku.

## Kabar dari orang lain

- "Budi menambahkan catatan.txt ke folder Kelas." saat seseorang menambah atau mengubah
  file di folder yang kamu bagikan. Beberapa perubahan disampaikan sekaligus, satu kalimat
  untuk tiap orang.
- "Budi membagikan tugas.docx denganmu." saat seseorang membagikan file atau folder
  denganmu. Hariku memeriksanya tiap lima menit; yang sudah dibagikan sebelum kamu
  menyambungkan Dropbox tidak diumumkan.

Dua kabar ini diam selama jam tenang. Satu suara lembut terdengar bersama kabar dari orang
lain, dan suara lain bersama "sudah tersinkron", "up to date", dan link yang disalin.

## Menyalin link

### File yang sedang kamu pilih di File Explorer

Di File Explorer, pilih sebuah file di folder Dropbox, buka Aruna, lalu ucapkan atau ketik
"salin link" atau "copy link" (bisa juga "salin link ini", "bagikan link ini", "salin link
dropbox", "copy this link"). Aruna menutup, File Explorer kembali mendapat fokus, link
bersama file itu disalin ke clipboard, dan Hariku bilang "Link laporan.pdf disalin."

- Hariku memakai file yang sedang kamu pilih kalau file itu terpilih, kalau tidak file
  terpilih yang pertama. Kalau tidak ada yang dipilih, yang disalin link folder tempat
  kamu berada.
- File yang sudah punya link bersama tetap memakai link itu. Kalau belum, link baru dibuat
  dengan pengaturan link akunmu yang biasa.
- Di luar folder Dropbox, Hariku bilang "File ini tidak ada di folder Dropbox." Folder
  Dropbox-nya sendiri tidak bisa diberi link. Untuk file yang belum ada di Dropbox, tunggu
  sampai tersinkron.
- Kalau jendela yang tadi kamu pakai bukan File Explorer, Hariku memintamu membuka folder
  Dropbox di sana dan memilih filenya dulu.

Kamu juga bisa memberi tombol untuk "Salin link Dropbox dari file yang dipilih di File
Explorer" (lihat Tombol dan perintah). Jadikan global supaya bekerja saat File Explorer
memegang fokus.

### File lewat namanya

Untuk menyalin link file yang tidak sedang kamu pilih, sebutkan namanya setelah
perintahnya: "salin link laporan", "copy link to the budget". Dropbox mencarinya lewat
nama:

- Satu yang jelas cocok: link-nya langsung disalin.
- Satu yang kemungkinan cocok: Aruna bertanya dulu, misalnya "Maksudmu laporan final.pdf
  di folder Kelas? Salin link-nya?"
- Beberapa yang cocok: Aruna membacakannya, supaya kamu bisa menyebutkan nama lengkapnya.

Kalau pencariannya lebih lama dari biasanya, jawabannya datang sebentar kemudian; yang
kemungkinan cocok lalu hanya disebutkan, dan kamu sebutkan nama lengkapnya untuk menyalin
link-nya.

## Memeriksa status sinkronisasi

Bilang "status dropbox", "apakah dropbox sudah up to date", "Dropbox status", atau cukup
"dropbox". Hariku menjawab "Dropbox-mu up to date.", atau file mana yang masih
disinkronkan atau belum tersinkron.

## Pengaturan

Buka Pengaturan lalu pilih Dropbox.

- Akun Dropbox: siapa yang tersambung, atau "Belum tersambung.", dengan tombol Sambungkan
  Dropbox atau Putuskan Dropbox.
- Kode dari Dropbox, dan Pakai kode: hanya muncul kalau masuknya butuh kode.
- Folder Dropbox di komputer ini: folder aplikasi Dropbox, atau alasan kabar tentang
  file-mu mati.
- Umumkan file yang sedang disinkronkan dan yang sudah tersinkron.
- Umumkan saat Dropbox-mu sudah up to date.
- Umumkan perubahan dari orang lain di folder bersama.
- Umumkan file dan folder yang dibagikan denganmu.
- Mainkan suara Dropbox.

Semuanya menyala sejak awal. Pilihan kotak centang disimpan saat kamu menekan OK atau
Terapkan.

## Tombol dan perintah

Perintah-perintah ini belum punya tombol. Kamu bisa memberinya tombol di Pengaturan,
Pintasan Keyboard, di bagian "Dropbox"; centang "Make this shortcut Global" supaya
tombolnya bekerja di jendela mana pun, termasuk File Explorer.

- Salin link Dropbox dari file yang dipilih di File Explorer: "salin link", "salin link
  ini", "salin link dropbox", "salin tautan", "bagikan link ini", "copy link", "copy this
  link", "copy dropbox link", "share this link".
- Status sinkronisasi Dropbox: "dropbox", "status dropbox", "sinkronisasi dropbox",
  "apakah dropbox sudah up to date", "Dropbox status", "is dropbox up to date".

Menyalin link file lewat namanya diawali "salin link", "salin tautan", "bagikan link",
"copy link to", "copy the link to", "copy link for", "copy link of", atau "share link to",
lalu namanya.

## Privasi

Ekstensi Dropbox hanya berhubungan dengan Dropbox setelah kamu menyambungkannya, dengan
tanda masukmu sendiri, dan pengembang Hariku tidak menerima apa pun. Selama Hariku
berjalan, Hariku menjaga sambungan ke Dropbox untuk mendengar perubahan, sampai kamu
memutuskannya.

- Masuknya lewat browser-mu, di situs Dropbox sendiri. Hariku meminta empat izin: nama dan
  email-mu, rincian file dan foldermu (bukan isinya), membaca link bersama, dan membuat
  link bersama.
- Yang dikirim ke Dropbox: lokasi file yang kamu ubah di folder Dropbox, untuk menanyakan
  apakah versi itu sudah sampai; lokasi file yang link-nya kamu salin, atau nama yang kamu
  cari; dan permintaan tentang apa yang berubah, apa yang dibagikan denganmu, dan siapa
  pelakunya.
- Untuk mengikuti file-mu, Hariku hanya membaca nama, ukuran, dan waktunya, tidak pernah
  isinya. Untuk tahu file mana yang kamu pilih di File Explorer, Hariku bertanya ke File
  Explorer di komputer ini; tidak ada yang dikirim ke mana pun, kecuali lokasi file itu
  saat kamu menyalin link-nya.
- Tanda masukmu disimpan di komputer ini, terenkripsi supaya hanya akun Windows-mu yang
  bisa membacanya. "Putuskan Dropbox" meminta Dropbox membatalkannya dan menghapusnya dari
  sini.
