# Key Notifier

Key Notifier memutar suara saat kamu menyalakan atau mematikan Caps Lock atau Num Lock.
Selama tombolnya masih menyala, ada suara pendek yang terus diulang, jadi kamu sadar
sebelum telanjur mengetik satu baris penuh dengan huruf kapital.

## Mulai

Begitu terpasang, ekstensi ini langsung bekerja untuk Caps Lock. Suaranya sudah ikut
dalam ekstensi. Untuk mengubah tombol yang dipantau atau suaranya, buka Pengaturan, Key
Notifier. Label di halaman itu hanya ada dalam bahasa Inggris.

## Pengaturan

Pengaturan, Key Notifier:

- "Monitor CapsLock": putar suara untuk Caps Lock. Menyala dari awal.
- "Monitor NumLock": putar suara yang sama untuk Num Lock. Mati dari awal.
- "ON Sound" dan "OFF Sound": suara saat tombol dinyalakan dan saat dimatikan. Ketik
  lokasi berkas WAV, atau tekan "Browse for the ON sound..." atau "Browse for the OFF
  sound..." lalu pilih berkasnya.
- "Enable Looping Sound": selama tombol yang dipantau masih menyala, "Loop Sound"
  diputar berulang-ulang. Menyala dari awal. Pilih suara ulangmu sendiri dengan "Browse
  for the loop sound...".
- "Loop Interval (seconds)": seberapa sering suara ulang diputar, dari 2 sampai 60
  detik. Bawaannya 2 detik.

Tekan Oke untuk menyimpan. Kalau kolom suara kosong, atau berkasnya sudah tidak ada,
yang terdengar bunyi bip standar Windows.
