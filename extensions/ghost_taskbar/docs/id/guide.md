# Ghost Taskbar Cleaner

Membersihkan ikon hantu di System Tray Windows: ikon program yang sudah ditutup atau
crash, tapi masih tertinggal di area notifikasi sampai mouse lewat di atasnya.

## Membersihkan tray

Tekan Ctrl+Alt+C, di mana saja di Windows. Hariku memberi tahu area notifikasi, termasuk
area ikon tersembunyi, bahwa mouse sudah lewat di setiap titiknya, supaya Windows sadar
ikon mana yang programnya sudah tidak ada lalu menghapusnya. Penunjuk mouse-mu sendiri
tidak bergerak.

Setelah selesai, Hariku bilang "System Tray dibersihkan." Kalau tray-nya tidak ketemu,
Hariku bilang "Gagal menemukan System Tray Windows."

## Tombol dan perintah

- Ctrl+Alt+C, di mana saja di Windows: Bersihkan Ikon Hantu di System Tray.

Tombolnya bisa kamu ganti di Pengaturan, Pintasan Keyboard, di bawah "Ghost Taskbar".
Aruna menjalankannya lewat namanya: ketik "bersihkan ikon hantu di system tray".
